The Hero Card Connection

Addendum to doc 115 (2026-08-28) — the iPhone screenshot traced to its exact mechanism, a correction to my first assessment, and one hardening fix.

1 · I said “probably not their bug”. I was wrong.

My first read: the hero’s crypto rows come from a fetch that never used the broken API, so the Safari fix “probably” did not cover the screenshot. That analysis stopped one layer too early — at the data, without checking the paint gate. The full chain, each link now verified in code:

1  The account is hybrid (Lobstr connected — visible in the screenshot's own labels),
   so the savings hook mounts its COMPANION lookup.
2  That lookup calls wallet-info → AbortSignal.timeout → on Safari < 16 it throws a
   synchronous TypeError. SWR retries 5×; every retry fails the same way instantly.
3  companionAddr.data stays undefined forever (a phone's first visit has no cache seed),
   so companionPositionLoading is stuck TRUE — by design, its "still loading" test is
   data === undefined, precisely so error retries don't flash a wrong $0.
4  The hero card deliberately waits for ALL slices before first paint
   ("so all assets paint together"): firstPaintDone requires
   !companionPositionLoading… which never comes.
5  → The entire card skeletons forever. The crypto rows — whose own fetch
   succeeded — never paint.  That is the screenshot.
So, straight
The AbortSignal fix from doc 115 very likely IS the coworker’s bug. Deploy, have them reload; if their iOS is < 16 the card comes back. The iOS-version + console ask stays only as the fallback if it somehow does not.

2 · The hardening: one slice can never blank the card again

Even with the data bug fixed, the design coupling remains: any future failure in the savings/companion chain that leaves its loading flag up would blank every row again. The first-paint gate now has a cap: after 8 seconds, the card paints what it has — crypto rows immediately, savings joining whenever its read lands. Aesthetic coupling is worth 8 seconds, never an infinite blank.
