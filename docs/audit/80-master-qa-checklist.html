Master QA Checklist

One document to test wallet creation & every swap flow on staging · branch feat/external-wallet-cctp · assembled 2026-08-22 from docs 73/77/78/79

How to use this
Work top to bottom. Each row has a Do and an Expect; tick the box when it matches. The status tag shows what we already know: verified live already passed a real test this cycle · not yet run needs your test · production only can't be tested on staging. If an Expect doesn't match, stop and note the row id — that's the bug report.
Staging setup & scope
  • Two test accounts: (A) a fresh account for the creation tests; (B) an account with a funded Lobstr external wallet (a few USDC + XLM) connected alongside the Normal wallet, for the hybrid swap tests.
  • Autopilot (1-signature): only active if the three AUTOPILOT_* env vars + both SQL migrations are present on staging. If not, autopilot rows should FALL BACK to normal prompts — that fallback is itself a valid pass.
  • Automated coverage: 291 unit tests run in CI (yarn test). They pin the pure decisions behind section 9 — passkey error mapping and transports, the pending-registration rules, the "path already exists" predicate, token identity, the autopilot gate and the backup no-nag rule. They cannot exercise a real passkey prompt, a real Turnkey account or a real bridge — which is exactly what the rows below are for.
  • Out of scope on staging: the "Deposit cash" (bank/card) on-ramp is production-only and is not tested here. Cross-chain swaps route through LI.FI, which has no testnet liquidity — so cross-chain + CCTP rows are run on mainnet with small real amounts.

9 · Passkey, provisioning & retry regressions (Aug 2026)
